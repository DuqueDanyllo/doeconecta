> Plataforma web desenvolvida para conectar doadores a instituições sociais, facilitando a gestão e o direcionamento de doações.

## 📌 Sobre o Projeto

O **Doe Conecta** nasce para resolver o desafio de ponte entre pessoas dispostas a doar e entidades que necessitam de suprimentos, recursos ou apoio voluntário. 

A aplicação oferece uma interface intuitiva para o cadastro de causas, mapeamento de necessidades e facilitação do contato direto com os responsáveis.

### ✨ Funcionalidades Planejadas & Em Desenvolvimento
- 🏛️ **Cadastro de Instituições:** Painel para ONGs e projetos sociais gerenciarem suas demandas.
- 🎁 **Mapeamento de Doações:** Categorização por itens (alimentos, roupas, brinquedos, recursos).
- 🔍 **Filtro de Causas:** Busca facilitada para doadores encontrarem projetos próximos.
- 📱 **Interface Responsiva:** Design otimizado para navegação via desktop e smartphones.

---

## 🛠️ Tecnologias e Ferramentas

### **Back-end & Banco de Dados**
- **Python:** Linguagem principal para regras de negócio.
- **Django:** Framework web robusto para estrutura MVC, ORM e autenticação.
- **SQLite / PostgreSQL:** Armazenamento de dados relacionais.

### **Front-end**
- **HTML5 & CSS3:** Estruturação semântica e estilização customizada.
- **JavaScript (ES6):** Interatividade de tela e requisições dinâmicas.
- **Bootstrap 5:** Componentes de interface e grid responsivo.
